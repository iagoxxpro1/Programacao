# 📖 Sobre o Projeto

Este projeto foi desenvolvido durante um desafio da **DIO (Digital Innovation One)** com o objetivo de demonstrar como utilizar ferramentas de Inteligência Artificial para criar um e-book profissional destinado à venda.

Todo o processo foi realizado com auxílio de IA, desde a pesquisa do mercado até a criação da página de vendas.

<a href="https://github.com/iagoxxpro1/Programacao/blob/main/formacao-chatGpt-dorDevs/criando-ebook-chatGPT/output/ebook%20Brilho%20e%20a%20Saude%20do%20seu%20PET.pdf" title="Ler o artigo"> 📕Clique aqui para ler o artigo</a>

---

# 🎯 Objetivo

Demonstrar um fluxo completo de produção de um e-book utilizando Inteligência Artificial para:

- Pesquisa de mercado
- Identificação de oportunidades
- Definição do público-alvo
- Produção do conteúdo
- Escrita persuasiva
- Criação da capa
- Formatação Kindle
- Preparação para venda

---

# 🚀 Ferramentas Utilizadas

| Ferramenta | Finalidade |
|------------|------------|
| ChatGPT | Pesquisa, criação do conteúdo e copy |
| Google Trends | Validação de demanda |
| Google Ads Keyword Planner | Pesquisa de palavras-chave |
| Microsoft Word | Escrita e formatação |
| Kindle Create | Conversão para Kindle |
| Gamma | Landing Page |

# 🧠 Prompts Utilizados

## 1️⃣ Pesquisa de Subnicho

Objetivo:

Encontrar um mercado com alta demanda e dores reais.

**Prompt**

```text
Quais os subnichos para e-book que possuem maior dor para donos de pet e que também apresentam alto volume de pesquisas?
```

---

## 2️⃣ Análise de Mercado

Objetivo:

Validar os subnichos encontrados.

**Prompt**

```text
Analise o mercado de pets para criação de um e-book de alta conversão...
```

---

## 3️⃣ Validação de Busca

Ferramentas utilizadas

- Google Trends

- Google Ads Keyword Planner

---

## 4️⃣ Definição do Público-Alvo

Objetivo:

Criar um perfil detalhado do leitor.

**Prompt**

```text
Nosso público-alvo é composto por homens e mulheres entre 25 e 34 anos...
```

---

## 5️⃣ Criação do Título

Objetivo:

Gerar títulos atrativos.

**Prompt**

```text
Crie um título chamativo para um e-book sobre...
```

---

## 6️⃣ Criação do Sumário

Objetivo:

Estruturar todo o conteúdo.

**Prompt**

```text
Crie um sumário completo para este e-book.
```

---

## 7️⃣ Escrita dos Capítulos

Para cada capítulo foram utilizados prompts específicos para:

- Introdução

- Desenvolvimento

- Exemplos

- Dicas práticas

---

## 8️⃣ Conclusão

Objetivo:

Reforçar os principais aprendizados e incentivar a ação.

---

## 9️⃣ Copy de Vendas

Objetivo:

Criar uma descrição persuasiva para venda do e-book.

Foram utilizados gatilhos como:

- Autoridade

- Escassez

- Urgência

- Benefícios

- CTA

---

## 🔟 Formatação Kindle

Boas práticas utilizadas:

✔ Heading 1

✔ Heading 2

✔ Sumário Automático

✔ Quebra de Página

✔ Kindle Create

---

## 1️⃣1️⃣ Criação da Capa

A IA também foi utilizada para gerar sugestões de capa adequadas ao tema do e-book.

---

## 1️⃣2️⃣ Landing Page

Após finalizar o conteúdo, foi criado um prompt para gerar uma página de vendas utilizando IA.
