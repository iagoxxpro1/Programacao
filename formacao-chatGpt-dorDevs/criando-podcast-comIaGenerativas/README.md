# 🎙️ Projeto Podcast Gerado por Inteligência Artificial

> ℹ️ Projeto desenvolvido como desafio da **DIO (Digital Innovation One)** utilizando ferramentas de Inteligência Artificial para transformar um e-book em um episódio de podcast.

O objetivo foi criar um episódio curto, informativo e descontraído, utilizando IA em todas as etapas do processo criativo: desenvolvimento do roteiro, geração das vozes e edição do áudio.

Neste projeto, o conteúdo do podcast foi baseado no e-book **"Brilho e a Saúde do seu PET"**, abordando como a alimentação natural pode contribuir para a saúde da pele e da pelagem dos cães.

# 💻 Tecnologias utilizadas

* ChatGPT
* Google NotebookLM

---

# ✨ Como o projeto foi desenvolvido

* 📖 O conteúdo foi extraído do e-book *Brilho e a Saúde do seu PET*.
* 🤖 O ChatGPT foi utilizado para criar um prompt completo e otimizado para geração do episódio.
* 🎙️ O Google NotebookLM gerou automaticamente a conversa entre dois apresentadores utilizando como fonte o próprio e-book.

---

# 🎯 Estrutura do episódio

O podcast possui aproximadamente **5 minutos** e foi desenvolvido em formato de conversa entre dois apresentadores.

Durante o episódio são abordados temas como:

* O impacto da alimentação na saúde da pele dos cães;
* O conceito de Nutrição Bioativa;
* Superalimentos importantes para a pelagem;
* A transição para alimentação natural;
* Receitas práticas apresentadas no e-book.

O objetivo não é substituir a leitura do material, mas despertar o interesse do ouvinte para conhecer o conteúdo completo.

# 🛠️ Como reproduzir este projeto

1. Utilize o e-book como fonte de conhecimento no Google NotebookLM.
2. Insira o prompt desenvolvido para orientar a criação do episódio.
3. Gere o podcast automaticamente.
4. Exporte o áudio.
5. Utilize o CapCut para realizar pequenos ajustes e adicionar música de fundo.
6. Exporte o resultado final em formato MP3.
