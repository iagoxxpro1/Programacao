# 🧠 Engenharia de Prompts — NotebookLM

Este documento reúne os prompts utilizados durante o estudo do tema **Brilho e a Saúde do seu PET**.

Todos os prompts foram desenvolvidos para utilização no **Google NotebookLM**, tendo como base exclusivamente as fontes adicionadas ao caderno.

---

# 📚 Resumos

## Prompt 1 — Resumo Geral

```text
Com base exclusivamente nas fontes fornecidas, apresente uma visão geral do conteúdo estudado.

Explique:

- Qual é o objetivo principal das fontes;
- Quais são os temas mais importantes;
- Como esses temas se relacionam entre si;
- Quais conhecimentos um tutor irá adquirir.

Organize em tópicos.
```

---

## Prompt 2 — Resumo Executivo

```text

```

---
